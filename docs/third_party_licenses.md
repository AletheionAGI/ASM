# Third-Party Licenses And Data Provenance

This file tracks bundled data and third-party artifacts that affect reuse of the repository.

Nothing listed here is relicensed under ASM's AGPL or alternative commercial
terms. Commercial deliveries exclude these artifacts by default under
[commercial_distribution.md](commercial_distribution.md) and the repository
root `commercial-exclusions.txt`.

## Bundled Data

### `data/wikipedia_en_20231101_sample.txt`

Purpose: optional local training/evaluation text for the 125M/350M scale comparison.

Provenance: generated by `scripts/prepare_wikipedia_en.py` from the Hugging
Face `wikimedia/wikipedia` dataset, config `20231101.en`, split `train`.

Upstream dataset: <https://huggingface.co/datasets/wikimedia/wikipedia>, which
identifies the text as `CC-BY-SA-3.0` and `GFDL`. Individual articles can carry
additional attribution or source-specific requirements; consult the article
URL and history retained by the upstream dataset before redistribution.

License boundary: this tracked research sample is not covered by ASM's
`AGPL-3.0-only` grant or alternative commercial license. It is excluded from
Python source distributions and commercial deliverables by default. Reuse or
redistribution requires compliance with the applicable Wikipedia licenses,
attribution, share-alike requirements, and any article-specific notices.

Research use: retained to reproduce historical language-model experiments.
Its presence does not authorize bundling it with a customer deployment.

### `data/tiny.txt`

Purpose: tiny local smoke-test corpus for training and generation workflows.

Provenance: project-authored text included in this repository.

License: covered by the repository license unless superseded by a more specific notice.

Notes: not a benchmark dataset and not suitable for model-quality claims.

## Generated Benchmark Artifacts

Files under `docs/benchmarks/` are generated experiment summaries, charts, dashboards, and tables from local project runs.

Provenance: generated by scripts in this repository.

License: covered by the repository license unless an individual artifact states otherwise.

## External Documents

No PDF is currently tracked in this repository. PDFs are excluded from default
commercial distributions. If a DRM paper or another external document is
added later, record its author, source, exact license, and redistribution
permission here before committing or delivering it.

## Maintenance Rule

When adding a new dataset, model checkpoint, pretrained artifact, image, or external document, add:

- path;
- source URL or author;
- license;
- whether redistribution is allowed;
- whether it may be used for training, evaluation, or documentation only.

Do not add the artifact if any required provenance or redistribution field is
unknown.
