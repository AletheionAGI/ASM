## New benchmark

ATTR-RTG-RCMZ compares four complete packages:

- ASM-R;
- ASM-CM;
- ASM-Z strict zero-choice;
- Transformer.

It follows the simplified RTG style: one HazardWorld plan, one common24 primary readout, six external candidates, a small metric set, six autonomous pairwise contrasts and one bootstrap family.

The only execution-specific extension is CUDA-first acceleration:

- batched origins;
- six candidates on one tensor axis;
- batched heads;
- FP64 CUDA metric/bootstrap tiles;
- deterministic prefetch and manifest preparation;
- independent seed jobs admitted only within the fixed memory cap;
- arms remain sequential if cross-arm concurrency changes determinism or memory.

No external ceremony, HSM, beacon, TSA, WORM, watchdog or remote attestation exists in the new design.
