# Project History

## 0.2.0 — Aletheion State Models

The project was renamed from **DRM Language Emitter** to **ASM — Aletheion
State Models** after component ablations showed that its scientific identity
needed to be broader than one geometric hypothesis.

The rename does not erase DRM:

- Directional Relational Manifolds remains the originating theory;
- ASM-X names the explicit DRM architecture;
- `drm_language_emitter` remains checkpoint- and import-compatible;
- `aletheion_state_models` provides the new neutral family namespace;
- historical reports, configs, run names, and data-format identifiers retain
  their original labels for reproducibility.

The initial ASM taxonomy is:

| Code | Architecture |
|---|---|
| ASM-X | Explicit DRM State Model |
| ASM-U | Metric Subspace State Model |
| ASM-F | Relational Frame State Model |
| ASM-R | Relational State Model |
| ASM-D | Direct State Model |
| ASM-S | Selective State Model |
| ASM-M | Causal Memory State Model |

No variant is declared the permanent winner by the rename. The promoted
architecture will be selected through continuous scaling-law evaluation,
compute efficiency, capability tests, and multiseed confirmation.

## 0.1.0 — DRM Language Emitter

The original project explored attention-free language modeling as movement of
a causal latent state through explicit learned directions and a relational
metric. Later work added blockwise causal approximation, direct token-state
paths, local mixing, and selective forget/write memory.

The historical name remains valid when referring to that original
architecture, its paper, or experiments performed before the ASM family was
introduced.
